# Predictive Modeling Using Machine Learning

## Project Title
Heart Disease Prediction Using Random Forest

## Objective
The objective of this project is to build a supervised machine learning model that predicts a target outcome from given data.

## Algorithm Used
- Random Forest Classifier

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- GitHub

## Project Steps
1. Load the dataset
2. Inspect the data
3. Handle missing values
4. Separate input features and target
5. Split the data into training and testing sets
6. Train a Random Forest model
7. Make predictions
8. Evaluate the model using accuracy and classification metrics
9. Visualize the confusion matrix
10. Visualize feature importance

## Dataset
The included `dataset.csv` is a demonstration classification dataset with 13 input features and a binary `target` column.

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python predictive_model.py
```

The program generates:
- `confusion_matrix.png`
- `feature_importance.png`

## Expected Output
The terminal displays the model accuracy, classification report, confusion matrix, and feature importance.

## Conclusion
This project demonstrates the complete supervised machine learning workflow, from data preparation and model training to evaluation and visualization.
